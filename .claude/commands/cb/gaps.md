```
cb index && cb gaps
```

Read the output and turn it into a short prioritised list for the analyst.
Rank by what would unblock an actual question, not by count:

- **unconfirmed-edge** — cheapest to fix and it makes verdicts provisional. Ask
  about the ones on paths that matter.
- **unannotated-table** / **column-without-timing** — the highest-value gap in
  the wiki. Whether a column is recorded before or after the treatment decides
  whether adjusting on it is a control or collider bias, and no semantic layer
  records it.
- **unobserved-node** — each one is a standing refusal. Is there a proxy?
- **stalled-question** — finish it or record why it was dropped.
- **question-without-interview** — context that was never captured.

Do not just relay the list. Say which two or three are worth doing now and why,
and offer to do them.
